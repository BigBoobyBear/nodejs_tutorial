# Node.js Tutorial

A Node.js and Express.js tutorial application demonstrating web application development with server-side rendering using EJS templates.

## Project Structure

```
nodejs_tutorial/
├── routes/          # Application routes
├── static/          # Static files (CSS, JS, images)
├── views/           # EJS templates
├── app.js          # Main application file
└── package.json
```

## Tech Stack

- **Node.js** - JavaScript runtime
- **Express.js** - Web application framework
- **EJS** - Embedded JavaScript templating
- **Body-Parser** - Parse incoming request bodies
- **Joi** - Data validation library

## Prerequisites

- Node.js (v14 or higher)
- npm

## Installation

1. Install dependencies:
```bash
npm install
```

2. Start the application:
```bash
node app.js
```

## Features

- Server-side rendering with EJS templates
- Request body parsing
- Data validation with Joi
- Static file serving
- Routing with Express Router

## Project Components

### Routes
Application routing logic for handling HTTP requests.

### Views
EJS templates for rendering dynamic HTML pages.

### Static
Public assets including:
- CSS stylesheets
- Client-side JavaScript
- Images and other static files

## Development

This is a tutorial project designed to learn fundamental Node.js and Express.js concepts including:
- Setting up an Express server
- Working with template engines (EJS)
- Handling routes and middleware
- Form validation
- Serving static files
